# brave browser

chromium based browsers are not configurable with source control.

so here is a manual guide on getting started:

## reset everything

> reset everything with `rm -rf ~/.config/BraveSoftware/Brave-Browser/` if desired

## upon first time opening

- set brave as default browser (asked upon opening first time)
- complete the wizard with obv choices

- hide the rewards icon in the address bar. right click hide
- hide the wallet icon in the top right next to the burger menu. right click hide

- right click the bookmarks section toggle "show tag groups" off

## get started

- new tab page: shows "blank page"

## appearance

- theme use classic > select dark
- beneath "show tab search button" toggle off
- disable autocompletion for leo assistant

## shields

- store contact information for future broken site reports > disable
- allow element blocking in private windows > enable

## privacy and security

- data collection: do not "automatically send daily usage ping to Brave"

## web3

- disable everything wallet related as good as possible

## leo ai

- disable everything you can find
- select chatgpt, still disable everything

## search engine

duckduckgo was the least disappointing, otherwise google

## autofill and passwords

- select password manager. open the burder menu top left. disable all
- save and fill payment methods > disable everything

## languages

- add german as third language
- enable spell check for german
- disable brave translate

## system

- disable "continue running background apps when Brave is closed"

## actual personalisation

install extensions:

- vimium
- optional: dark reader
- optional: uorigin block light
  (non light version can be enabled in manifest v2 settings)

on google search:

- spracheinstellung: english
