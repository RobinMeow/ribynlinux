# fps to milliseconds comparison

At 60 frames per second (fps), each frame lasts exactly 16.67 milliseconds (ms).

## How it is calculated

To find the frame time, divide 1 second (1,000 milliseconds) by the frame rate:
$$\text{Frame Time} = \frac{1000\text{ ms}}{60\text{ fps}} = 16.666... \text{ ms}$$

## common frame rates

| Frame Rate (FPS) | Frame Time (ms) |
| --- | --- |
| 30 fps | 33.33 ms |
| 60 fps | 16.67 ms |
| 120 fps | 8.33 ms |
| 144 fps | 6.94 ms |
| 240 fps | 4.17 ms |
